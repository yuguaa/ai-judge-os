# ai-judge-os

阅卷平台的 AI 判卷工具：框选屏幕上的答题区与给分板输入框，接入视觉大模型逐张判分，支持手动提交与自动评卷两种模式。

## 功能

- **区域框选**：全屏覆盖层拖拽框选，框选结果以彩色边框常驻屏幕（答题区蓝 / 输入框橙，点击穿透）
- **模型接入**：任意 OpenAI 兼容服务（DeepSeek / Qwen-VL / GLM-4V / Kimi / 本地 ollama 等），判分强制 JSON 输出，分数与逐条判定结构化留档
- **评分规则**：纯文本规则，题型无关（填空 / 选择 / 解答均可），在设置弹窗中自由书写
- **对话调试**：带截图与模型反复确认判分口径，结论一键追加进规则
- **手动模式**：模型判分、你点提交，逐张循环
- **自动模式**：模型接管提交（点击聚焦输入框 → 键入分数 → 校验生效 → 回车），到达设定数量自动停止
- **安全机制**：低置信度 / 键入未生效 / 等卷超时自动暂停报警，处理完点「继续」；每张卷截图与判定全程留档，误判可用「回评上一份」修正

## 快速开始

### 开发模式

```bash
npm install
npm run dev
```

### 打包成应用

```bash
npm run pack    # 仅生成 dist/mac-arm64/ai-judge-os.app
npm run dist    # 额外生成 dmg 安装镜像
```

双击 `ai-judge-os.app` 即可使用。

## 系统权限（macOS）

首次使用需要两项权限，在 **系统设置 → 隐私与安全性** 中开启：

| 权限 | 用途 | 授权对象 |
|------|------|----------|
| 屏幕录制 | 截取答题区与输入框画面 | 开发模式授权给运行命令的终端；打包版授权给 ai-judge-os |
| 辅助功能 | 模拟点击与键盘输入（自动模式） | 同上 |

授权后需重启终端或应用生效。窗口内 ⚙ 设置可实时查看两项权限的实测状态。

## 使用流程

1. ⚙ **设置**：填入 Base URL / API Key / 视觉模型名；检查评分规则文本
2. **框选答题区**：点击控制条「答题区」按钮，拖拽框住题目作答区域，屏幕出现蓝色边框
3. **对话调试**（可选）：💬 把当前卷发给模型试判，确认口径后「存入规则」
4. **自动模式**：先点「输入框」框住给分板分数输入框（橙色边框），切换「自动」并设置数量
5. **开始**：切到阅卷页面放好第一张卷，点 ▶ 开始
6. 手动模式判分后自行点「提交得分(Enter)」；自动模式全程接管

## 注意事项

- 判分分数以模型按规则文本计算为准；模型自报分与逐条判定不一致时自动标记低置信
- 自动模式运行期间保持窗口在前台且不被遮挡
- 涂改卷面默认以最后书写的词为准，可在规则文本中自行约定
- 本工具仅辅助评卷，最终成绩以平台数据为准，请抽查复核
